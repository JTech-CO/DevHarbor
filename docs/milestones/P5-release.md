# P5 — Windows 베타 배포

상태: 대기. 선행: P0–P4. 담당: Desktop, 배포/QA.

## 작업

1. 사용자 범위 설치, 안정된 MCP exe 경로, 제거 시 복구 기록 보존 정책을 확정한다.
2. Windows 코드 서명과 업데이트 서명 검증, 실패 시 기존 버전 유지·원장 호환성을 검증한다.
3. 새 Windows 사용자/표준 권한/한국어·공백 경로/DPI/키보드/스크린리더를 시험한다.
4. 지원 버전·알려진 제한·복구 절차·개인정보·MIT 고지를 패키지에 포함한다.
5. SDK/fixture/개인 경로/비밀 정보가 배포에 없는지 검사한다.

## 산출물 및 게이트

서명된 베타 패키지, 설치/업데이트/제거 QA 증거, 복구 리허설, 지원 범위 표. 보호 대상 변경·승인 밖 변경·복구 과장·공간 과대 보고가 하나라도 발견되면 배포 중단한다.

상표·코드 서명 계정 등 외부 결정은 이 단계의 명시적 의존 사항이며 보유한 것으로 가정하지 않는다. 유료화와 계정 체계는 별도 기획한다.
