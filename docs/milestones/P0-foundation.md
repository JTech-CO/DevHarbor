# P0 — 제품 계약과 개발 기반

상태: 로컬 완료 (2026-09-25). 목표는 다음 구현 단계가 추측 없이 시작할 수 있는 기반을 만드는 것이다. 원격 CI 실행은 별도 상태다.

## 작업과 산출물

- [x] 독립 브랜드와 저장소 연결, 기존 MIT 라이선스 유지.
- [x] 이전 제품 배포 자료·이전 포팅 문서 제거.
- [x] P0–P5별 의존 관계, 범위, 완료 게이트 문서화.
- [x] ADR-001: .NET 10 LTS, WPF, SQLite, 사용자 권한, 읽기 전용 기본값 결정.
- [x] adapter capability·근거·크기·보호 정책 계약 정의.
- [x] Domain 프로젝트와 executable 정책 검증 프로젝트 빌드.
- [x] 로컬 검증 스크립트와 Windows CI 구성.
- [x] 검증 결과와 남은 위험을 [P0 결과](P0-results.md)에 기록.

## 정책 기준

현재 사용자·Windows 11 x64·로컬 NTFS를 지원 목표로 삼는다. root 전체, 사용자 자산, 자격 증명, 원격 Docker context, 알 수 없는 저장소 형식은 변경 불가다. 접근 불가는 0바이트로 표현하지 않는다. 앱과 MCP가 같은 Domain 정책을 소비하며 최종 변경 권한은 executor에만 있다.

P0에서는 모든 변경 capability를 비활성화한다. 테스트가 향후 조건 충족 여부를 판정하더라도 실제 삭제 API를 호출하지 않는다. 원본 복원·재다운로드·자동 재생성을 구분한다.

## 완료 증거

SDK 버전 고정, 솔루션 Release 빌드, 의미 있는 정책 테스트, `git diff --check`, 관리 대상 텍스트의 이전 브랜드 참조 제거를 확인한다. CI는 구성과 로컬 결과를 구분하고 원격에서 실행하지 않았으면 미실행으로 표기한다.

## 제외

실제 삭제 executor, WPF 제품 화면, 사용자 승인 IPC, SQLite 원장, 도구 실환경 스캐너는 후속 단계다. 기존 안전성 실험의 공개 테스트 승인 메서드를 제품 API로 옮기지 않는다.
